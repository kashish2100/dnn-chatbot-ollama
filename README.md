
# DNN-Based Chatbot with Ollama & Scikit-learn

A conversational chatbot built using a Deep Neural Network (DNN) architecture,
developed in Python as part of my M.Sc. Data Science program (2025).

## 🔧 Tech Stack
- Python
- Jupyter Notebook
- Ollama (LLM integration)
- Scikit-learn (model utilities)
- Pandas / NumPy

## 💡 What it does
- Takes user input and generates context-aware responses
- Uses a DNN model for intent classification / response generation
- Integrated with Ollama for language model capabilities

## 📁 Files
| File | Description |
|------|-------------|
| `DNN Chatbot.ipynb` | Main notebook — full code and explanation |

## 🚀 How to run
1. Install dependencies: `pip install ollama scikit-learn pandas numpy`
2. Open `chatbot.ipynb` in Jupyter
3. Run all cells
